Docker 与 Podman，在 KDE 面板里井然有序

Dockyard 是一款免费开源的 Plasma 6 小部件：一眼看清所有容器，无需离开桌面就能启动、停止、重启、查看日志和清理。为 Fedora KDE 打造。

一条命令安装★ 在 GitHub 上加星标KDE Store

免费 · MIT 许可证 · 无遥测 · 支持 Docker、rootless Docker 和 Podman

整个容器集群，画成一艘船的货物清单

  • 运行中
  • 需要关注
  • 已暂停
  • 已停止

每个格子是一个容器，颜色对应状态。状态变化时格子位置不变，所以问题会自己跳出来，不用你去找。点击格子，列表就跳到该容器。每种状态还有自己的形状，即使分不清颜色也能读懂。

出问题之前就知道

所有运行中容器的 CPU 和内存，带历史曲线。一键筛选：运行中、需要关注、已停止。容器崩溃、变为不健康或循环重启时，你会收到桌面通知。

  • 容器按 Compose 项目分组
  • 整个项目可一次启动、停止或重启
  • 每个容器的 CPU、内存和网络实时显示

引擎知道的一切

镜像、卷和网络只隔一个标签页，带有“使用中”和“未使用”标记。删除不需要的；如果仍在使用，引擎会拒绝，Dockyard 会告诉你原因。清理面板会在你确认之前说明每项操作会删除什么、能释放多少空间。

  • 悬空和未使用的镜像、匿名卷、构建缓存
  • 命名卷绝不会被清理触碰
  • 两步确认，而不是模态对话框

出问题时也从容

Docker 未运行、没有套接字权限、没有安装引擎：Dockyard 用通俗的话说明发生了什么，并给出准确的解决方法，还有一键复制或启动 Docker 的按钮。

  • 自动识别 Docker、rootless Docker 和 Podman
  • 随时打开任何容器的彩色实时日志
  • 一键在容器中打开 Shell

说你的语言

Dockyard 跟随系统语言，弹窗里的地球按钮可随时切换。增加一种语言只需要一个文件，不需要写代码。

一应俱全

  • 清单条: 整个集群一排可点击的格子
  • 集群指标: 带历史的 CPU 和内存
  • 支持 Compose: 项目分组、折叠和批量操作
  • 实时日志: 彩色、暂停、复制
  • Shell 访问: 在 Konsole 中打开 bash 或 sh
  • 可点击的端口: 在浏览器中打开或复制地址
  • 镜像、卷、网络: 标记、筛选、安全删除
  • 释放空间: 确认前先给出大小和说明
  • 通知: 崩溃、健康检查失败、循环重启
  • 深色与浅色: 跟随 Plasma 配色和字体
  • 无障碍: 处处可用键盘，状态还用形状表示
  • 多语言: 在小部件里选择，易于扩展

在 Fedora KDE 上一分钟内完成安装

  1. 确认基本条件

    KDE Plasma 6、Python 3（Fedora 已自带），以及 Docker 或 Podman。仅此而已。

  2. 安装小部件

    按用户安装，无需 root。

    git clone https://github.com/phuonghx/dockyard
cd dockyard && ./install.sh --restart

  3. 添加到面板

    右键点击面板，选择“添加小部件”，搜索 Dockyard 并拖入。想先试用，可运行 plasmawindowed io.dockyard.widget。

连不上 Docker？把自己加入 docker 组，然后注销并重新登录：sudo usermod -aG docker $USER。Podman 用户：systemctl --user enable --now podman.socket。

更新：git pull && ./install.sh。卸载：./install.sh --uninstall。

常见问题

Dockyard 是什么？

Dockyard 是一款免费开源的 KDE Plasma 6 小部件。它常驻在面板上，让你无需打开终端或笨重的应用，就能监控和管理 Docker 或 Podman 的容器、镜像、卷和网络，查看日志并释放磁盘空间。

Dockyard 支持 Podman 吗？

支持。它会自动发现 Docker、rootless Docker 和 Podman 的 Docker 兼容套接字，也可以在小部件设置里指定套接字路径。

支持哪些系统？

任何运行 KDE Plasma 6 的 Linux 桌面，已在 Fedora KDE 上测试。它是 Plasma 小部件，因此不能在 GNOME 等其他桌面上运行。

需要 Docker Desktop 或其他软件吗？

不需要。只要有 Python 3 和正在运行的 Docker 或 Podman 引擎即可。Dockyard 直接与引擎的本地套接字通信。

安全吗？会发送数据吗？

Dockyard 没有遥测，除了本地引擎套接字外不会向任何地方发送数据。采用 MIT 许可证，源代码在 GitHub 上。和所有 Docker 工具一样，访问 Docker 套接字相当于拥有 root 权限。

怎样获得使用 Docker 的权限？

运行 sudo usermod -aG docker $USER 把你的用户加入 docker 组，然后注销并重新登录。Dockyard 检测到问题时会直接显示这条命令。

我能把它翻译成自己的语言吗？

可以。用 tools/i18n.sh new <语言> 生成模板，用任意编辑器翻译文件，然后提交 pull request。无需编程。请参阅 CONTRIBUTING.md 中的 Translating 指南。
