Docker и Podman в порядке, прямо на панели KDE

Dockyard — бесплатный виджет Plasma 6 с открытым кодом: он показывает все контейнеры с одного взгляда и позволяет запускать, останавливать, перезапускать, читать журналы и наводить порядок, не выходя с рабочего стола. Создан для Fedora KDE.

Установить одной командой★ Поставить звезду на GitHub

Бесплатно · Лицензия MIT · Без телеметрии · Docker, rootless Docker и Podman

Весь ваш парк, нарисованный как грузовой манифест корабля

  • Работает
  • Требует внимания
  • На паузе
  • Остановлен

Каждая ячейка — один контейнер, цвет зависит от состояния. Ячейки остаются на месте при смене состояния, поэтому проблема заметна сама, без поисков. Щёлкните ячейку, и список перейдёт к этому контейнеру. У каждого состояния есть и своя форма, так что всё читается и без различения цветов.

Узнайте до поломки

ЦП и память всего запущенного с историей. Фильтры в один щелчок: работают, требуют внимания, остановлены. Когда контейнер падает, становится нездоровым или перезапускается в цикле, вы получаете уведомление на рабочем столе.

  • Контейнеры сгруппированы по проектам Compose
  • Запуск, остановка и перезапуск всего проекта сразу
  • ЦП, память и сеть в реальном времени по каждому контейнеру

Всё, что известно движку

Образы, тома и сети — на соседней вкладке, с метками «Используется» и «Не используется». Удаляйте лишнее; если что-то ещё используется, движок откажет, а Dockyard объяснит почему. Панель очистки показывает перед подтверждением, что удалит каждое действие и сколько места освободит.

  • Висячие и неиспользуемые образы, анонимные тома, кэш сборки
  • Именованные тома очистка никогда не трогает
  • Двойное подтверждение вместо модальных окон

Спокойствие, когда что-то не так

Docker не запущен, нет доступа к сокету, движок не установлен: Dockyard простыми словами объясняет, что случилось, и даёт точное решение, с кнопкой копирования или запуска Docker.

  • Сам находит Docker, rootless Docker и Podman
  • Открывайте цветные журналы любого контейнера в реальном времени
  • Оболочка в контейнере одним щелчком

Говорит на вашем языке

Dockyard следует языку системы, а кнопка с глобусом во всплывающем окне позволяет сменить его в любой момент. Чтобы добавить язык, нужен один файл и никакого кода.

Всё в комплекте

  • Полоса манифеста: весь парк одной кликабельной строкой
  • Показатели парка: ЦП и память с историей
  • Понимает Compose: группировка, сворачивание, действия над проектами
  • Журналы в реальном времени: с цветом, пауза, копирование
  • Доступ к оболочке: bash или sh в Konsole
  • Кликабельные порты: открыть в браузере или скопировать адрес
  • Образы, тома, сети: метки, фильтры, безопасное удаление
  • Освободить место: с цифрами и пояснением до подтверждения
  • Уведомления: падения, сбои проверок состояния, циклы перезапуска
  • Тёмная и светлая: следует схеме и шрифту Plasma
  • Доступность: фокус с клавиатуры везде, состояние ещё и формой
  • Много языков: выбор в виджете, легко расширять

Установка на Fedora KDE меньше чем за минуту

  1. Проверьте основное

    KDE Plasma 6, Python 3 (в Fedora уже есть) и Docker или Podman. Больше ничего.

  2. Установите виджет

    Для одного пользователя, без root.

    git clone https://github.com/phuonghx/dockyard
cd dockyard && ./install.sh --restart

  3. Добавьте на панель

    Правый щелчок по панели, «Добавить виджеты», найдите Dockyard и перетащите. Чтобы сначала попробовать: plasmawindowed io.dockyard.widget.

Нет доступа к Docker? Добавьте себя в группу docker и перезайдите: sudo usermod -aG docker $USER. Для Podman: systemctl --user enable --now podman.socket.

Обновление: git pull && ./install.sh. Удаление: ./install.sh --uninstall.

Частые вопросы

Что такое Dockyard?

Dockyard — бесплатный виджет с открытым кодом для KDE Plasma 6. Он живёт на вашей панели и позволяет следить за контейнерами, образами, томами и сетями Docker или Podman и управлять ими, читать журналы и освобождать место на диске, не открывая терминал или тяжёлое приложение.

Работает ли Dockyard с Podman?

Да. Он сам находит Docker, rootless Docker и совместимый с Docker сокет Podman, либо вы указываете путь к сокету в настройках виджета.

Какие системы поддерживаются?

Любой рабочий стол Linux с KDE Plasma 6, проверено на Fedora KDE. Это виджет Plasma, поэтому он не работает в GNOME и других средах.

Нужен ли Docker Desktop или другое ПО?

Нет. Нужны Python 3 и работающий движок Docker или Podman. Dockyard общается напрямую с локальным сокетом движка.

Это безопасно? Отправляет ли он данные?

В Dockyard нет телеметрии, он ничего не отправляет, кроме обращений к локальному сокету вашего движка. Лицензия MIT, исходный код на GitHub. Как и с любым инструментом Docker, доступ к сокету Docker равносилен root.

Как получить право использовать Docker?

Добавьте пользователя в группу docker командой sudo usermod -aG docker $USER и перезайдите в систему. Dockyard показывает именно эту команду, когда замечает проблему.

Можно ли перевести его на мой язык?

Да. Создайте шаблон командой tools/i18n.sh new <язык>, переведите файл в любом редакторе и откройте pull request. Программировать не нужно. См. руководство Translating в CONTRIBUTING.md.
