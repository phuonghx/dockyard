Docker and Podman, shipshape in your KDE panel

Dockyard is a free, open-source Plasma 6 widget that shows every container at a glance and lets you start, stop, restart, read logs and clean up, without leaving your desktop. Built for Fedora KDE.

Install in one command★ Star on GitHubKDE Store

Free · MIT license · No telemetry · Docker, rootless Docker and Podman

Your whole fleet, drawn as a cargo manifest

  • Running
  • Needs attention
  • Paused
  • Stopped

Each cell is one container, coloured by state. Cells keep their place when a state changes, so a problem stands out without you hunting for it. Click a cell and the list jumps to that container. Every state also has its own shape, so it reads without colour vision.

Know before it breaks

CPU and memory for everything that is running, with history. One-click filters for running, needs attention and stopped. When a container crashes, turns unhealthy or restart-loops, you get a desktop notification.

  • Containers grouped by Compose project
  • Start, stop or restart a whole project at once
  • Live CPU, memory and network per container

Everything the engine knows

Images, volumes and networks sit one tab away, with In use and Unused badges. Remove what you do not need; if something is still in use, the engine refuses and Dockyard tells you why. The clean-up panel shows what each action removes and how much it frees before you confirm.

  • Dangling and unused images, anonymous volumes, build cache
  • Named volumes are never touched by clean-up
  • Two-step confirmation instead of modal dialogs

Calm when things go wrong

Docker not running, no permission on the socket, no engine installed: Dockyard says what happened in plain language and gives the exact fix, with a button to copy it or to start Docker.

  • Detects Docker, rootless Docker and Podman automatically
  • Open any container’s live, colour-coded logs
  • Shell into a container in one click

Speaks your language

Dockyard follows your system language, and the globe button in the popup lets you switch at any time. Adding another takes one file and no code.

Everything in the box

  • Manifest strip: the whole fleet as one clickable row
  • Fleet metrics: CPU and memory with history
  • Compose aware: group, collapse and act on projects
  • Live logs: colour-coded, pause, copy
  • Shell access: open bash or sh in Konsole
  • Clickable ports: open in the browser or copy the address
  • Images, volumes, networks: badges, filters, safe removal
  • Free up space: sized and explained before you confirm
  • Notifications: crashes, failing health checks, restart loops
  • Dark and light: follows your Plasma colour scheme and font size
  • Accessible: keyboard focus everywhere, state shown by shape too
  • 9 languages: gettext translations, easy to extend

Install on Fedora KDE in under a minute

  1. Check you have the basics

    KDE Plasma 6, Python 3 (already on Fedora), and Docker or Podman. Nothing else.

  2. Install the widget

    Per user, no root needed.

    git clone https://github.com/phuonghx/dockyard
cd dockyard && ./install.sh --restart

  3. Add it to your panel

    Right-click the panel, choose Add Widgets, search for Dockyard and drag it in. To try it first, run plasmawindowed io.dockyard.widget.

Can’t reach Docker? Add yourself to the docker group, then log out and in: sudo usermod -aG docker $USER. For Podman: systemctl --user enable --now podman.socket.

Update with git pull && ./install.sh. Remove with ./install.sh --uninstall.

Frequently asked questions

What is Dockyard?

Dockyard is a free, open-source widget for KDE Plasma 6. It lives in your panel and lets you monitor and manage Docker or Podman containers, images, volumes and networks, read logs and free up disk space, without opening a terminal or a heavy desktop app.

Does Dockyard work with Podman?

Yes. It finds Docker, rootless Docker and Podman’s Docker-compatible socket automatically, or you can set a socket path in the widget settings.

Which systems does it support?

Any Linux desktop running KDE Plasma 6, tested on Fedora KDE. It is a Plasma widget, so it does not run on GNOME or other desktops.

Do I need Docker Desktop or other software?

No. You need Python 3 and a running Docker or Podman engine. Dockyard talks to the engine’s local socket directly.

Is it safe? Does it send any data?

Dockyard has no telemetry and sends nothing anywhere except to your local engine socket. It is MIT-licensed and the source is on GitHub. Note that access to the Docker socket is equivalent to root, as with any Docker tool.

How do I get permission to use Docker?

Add your user to the docker group with sudo usermod -aG docker $USER and log out and in again. Dockyard shows this exact command if it detects the problem.

Can I translate it into my language?

Yes. Copy the template with tools/i18n.sh new <lang>, translate the file with any editor, and open a pull request. No programming is needed. See the Translating guide in CONTRIBUTING.md.

Free and open source
