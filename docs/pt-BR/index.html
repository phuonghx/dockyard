Docker e Podman em ordem, direto no painel do KDE

O Dockyard é um widget gratuito e de código aberto para o Plasma 6 que mostra todos os contêineres num relance e deixa você iniciar, parar, reiniciar, ler logs e limpar sem sair da área de trabalho. Feito para o Fedora KDE.

Instalar com um comando★ Dar uma estrela no GitHub

Grátis · Licença MIT · Sem telemetria · Docker, Docker rootless e Podman

Toda a sua frota, desenhada como o manifesto de carga de um navio

  • Em execução
  • Precisa de atenção
  • Pausado
  • Parado

Cada célula é um contêiner, colorida pelo estado. As células mantêm o lugar quando o estado muda, então um problema aparece sem você procurar. Clique numa célula e a lista pula para aquele contêiner. Cada estado também tem sua própria forma, para ser legível sem distinguir cores.

Saiba antes de quebrar

CPU e memória de tudo que está rodando, com histórico. Filtros de um clique: em execução, precisam de atenção, parados. Quando um contêiner cai, fica não saudável ou reinicia em loop, você recebe uma notificação na área de trabalho.

  • Contêineres agrupados por projeto do Compose
  • Inicie, pare ou reinicie um projeto inteiro de uma vez
  • CPU, memória e rede ao vivo por contêiner

Tudo o que o mecanismo conhece

Imagens, volumes e redes ficam a uma aba, com selos Em uso e Sem uso. Remova o que não precisa; se algo ainda está em uso, o mecanismo recusa e o Dockyard diz por quê. O painel de limpeza mostra o que cada ação remove e quanto libera antes de você confirmar.

  • Imagens órfãs e sem uso, volumes anônimos, cache de build
  • Volumes nomeados nunca são tocados pela limpeza
  • Confirmação em duas etapas em vez de diálogos modais

Calmo quando algo dá errado

Docker parado, sem permissão no socket, sem mecanismo instalado: o Dockyard explica o que houve em linguagem simples e dá a correção exata, com um botão para copiá-la ou para iniciar o Docker.

  • Detecta Docker, Docker rootless e Podman automaticamente
  • Abra os logs ao vivo e coloridos de qualquer contêiner
  • Abra um shell no contêiner com um clique

Fala o seu idioma

O Dockyard segue o idioma do seu sistema, e o botão de globo no popup permite trocar a qualquer momento. Adicionar outro idioma exige um arquivo e nenhum código.

Tudo incluído

  • Faixa de manifesto: toda a frota numa fileira clicável
  • Métricas da frota: CPU e memória com histórico
  • Compatível com Compose: agrupe, recolha e aja sobre projetos
  • Logs ao vivo: coloridos, pausa, cópia
  • Acesso ao shell: abra bash ou sh no Konsole
  • Portas clicáveis: abra no navegador ou copie o endereço
  • Imagens, volumes, redes: selos, filtros, remoção segura
  • Liberar espaço: medido e explicado antes de confirmar
  • Notificações: quedas, verificações de saúde falhando, loops de reinício
  • Escuro e claro: segue o esquema de cores e a fonte do Plasma
  • Acessível: foco de teclado em tudo e estado também pela forma
  • Vários idiomas: escolha no widget, fácil de ampliar

Instale no Fedora KDE em menos de um minuto

  1. Confira o básico

    KDE Plasma 6, Python 3 (já vem no Fedora) e Docker ou Podman. Nada mais.

  2. Instale o widget

    Por usuário, sem precisar de root.

    git clone https://github.com/phuonghx/dockyard
cd dockyard && ./install.sh --restart

  3. Adicione ao painel

    Clique com o botão direito no painel, escolha Adicionar widgets, procure Dockyard e arraste. Para testar antes, execute plasmawindowed io.dockyard.widget.

Sem acesso ao Docker? Adicione-se ao grupo docker e faça login de novo: sudo usermod -aG docker $USER. Com Podman: systemctl --user enable --now podman.socket.

Atualize com git pull && ./install.sh. Remova com ./install.sh --uninstall.

Perguntas frequentes

O que é o Dockyard?

O Dockyard é um widget gratuito e de código aberto para o KDE Plasma 6. Ele fica no seu painel e permite monitorar e gerenciar contêineres, imagens, volumes e redes do Docker ou do Podman, ler logs e liberar espaço em disco, sem abrir um terminal nem um aplicativo pesado.

O Dockyard funciona com Podman?

Sim. Ele encontra automaticamente o Docker, o Docker rootless e o socket compatível com Docker do Podman, ou você informa o caminho de um socket nas configurações do widget.

Quais sistemas são suportados?

Qualquer desktop Linux com KDE Plasma 6, testado no Fedora KDE. É um widget do Plasma, então não roda no GNOME nem em outros desktops.

Preciso do Docker Desktop ou de outro software?

Não. Você precisa do Python 3 e de um mecanismo Docker ou Podman em execução. O Dockyard conversa direto com o socket local do mecanismo.

É seguro? Envia algum dado?

O Dockyard não tem telemetria e não envia nada além do socket local do seu mecanismo. Tem licença MIT e o código está no GitHub. Como em qualquer ferramenta Docker, acessar o socket do Docker equivale a ser root.

Como consigo permissão para usar o Docker?

Adicione seu usuário ao grupo docker com sudo usermod -aG docker $USER e faça login de novo. O Dockyard mostra esse comando exato quando detecta o problema.

Posso traduzi-lo para o meu idioma?

Sim. Crie o modelo com tools/i18n.sh new <idioma>, traduza o arquivo em qualquer editor e abra um pull request. Não precisa programar. Veja o guia Translating no CONTRIBUTING.md.
